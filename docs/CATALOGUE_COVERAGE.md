# Catalogue coverage

As of 12 October 2026 (v0.8.0), GradAtlas contains **1,489 programme and named-specialisation records**, across **88 countries/regions** and **17 discovery subject groups**.

| Evidence tier | Records | What the count establishes |
| --- | ---: | --- |
| Programme-page records | 358 | Named master's degrees/specialisations with reviewed official programme sources; admissions fields remain partial |
| DUO RIO identity records | 1,131 | Registered Dutch master's identities after grouping and duplicate reconciliation; individual admissions and current intake unreviewed |
| Separate ROR institution directory | 30,174 | Active education-type identities in 223 countries/territories; no degree or eligibility inference |

The 107 curated additions in this release cover Europe, the Netherlands, UK, Ireland, USA and Canada. The DUO import broadens subjects substantially within the Netherlands, so it does not make international programme coverage geographically even. The curated world catalogue remains selective. Institution coverage must never be added to the master's programme total.

Parent degrees and explicitly named specialisations can coexist. Different delivery modes, repeated offerings, duplicate joint providers and identically named registry codes are not used to inflate the count. Source review and import audits are in [research](research/2026-10-12-duo-import.md).

Field-level evidence distinguishes linked sources, recorded facts awaiting a specific source and missing information. Registry language describes registered offerings, not a guaranteed English-only route. Duration, mode, fees, GPA, IELTS, deadlines and contacts remain unknown in identity-only DUO records. Locations are approximate institution localities and can differ from teaching campuses.

Neither a validator, an HTTP response, a review date nor an open licence guarantees current factual accuracy. Always double-check the relevant university's current instructions and applicant category. The service is a research aid, not an admissions decision engine or a complete worldwide degree database.
