# GradAtlas worldwide institution index: ROR

Verified 12 October 2026. ROR is a reusable research-organization registry with persistent identifiers and curated institution metadata. It is suitable for an institution discovery layer, while master’s programmes retain their separately verified catalogue. ROR is research-focused and does not establish accreditation, university status, degree availability or admissions eligibility. [Official scope](https://ror.org/registry)

## Geographic and identity handling

Use `names[].types` containing `ror_display` for display; retain other name values for search. Preserve the full ROR `id`, and select `links[]` of type `website`. Geographic fields are in `locations[].geonames_details`, including `lat`, `lng`, country names/codes and place name. These coordinates describe a city or the most granular available administrative region, not a verified campus building. [Exact subfields](https://ror.readme.io/docs/fields)

There are only 9,578 distinct coordinate pairs across the full education location set. Clustering and an institution list are necessary because many organizations share city coordinates. Do not add synthetic offsets while claiming those offsets are real campus positions. The prepared compact map projection selects each institution’s first valid location as requested, keeping one point per ROR ID.

## Reuse and attribution

ROR metadata is offered under CC0 1.0. GeoNames geographic data has separate attribution terms: the current release and GeoNames state CC BY 4.0, while one ROR schema documentation paragraph still mentions CC BY 3.0. Preserve GeoNames credit, provider and licence links, plus a transformation notice; retain the legacy-link context in the manifest. [ROR licensing](https://ror.readme.io/docs/data-dump), [GeoNames reuse terms](https://www.geonames.org/export/), [GeoNames current licence notice](https://www.geonames.org/about.html), [CC BY 4.0 terms](https://creativecommons.org/licenses/by/4.0/)

## Reproducible import

Run `scripts/import-ror.py` against the pinned archive using `data-sources/ror-v2.14.json`. The published files are `src/data/institutions.json` and `src/data/institution-manifest.json`. The importer verifies the archive checksum, preserves one stable ROR ID per record and uses the first valid GeoNames locality. It does not infer programme facts or invent campus offsets. The manifest records release provenance and output SHA-256. The production index is loaded on request, and results render in pages of 50 with native map clustering.

Refresh by reviewing a new official release, its checksum, schema, licence and changes in withdrawn IDs before replacing the pinned index. Registry websites are not all independently checked. Admissions facts remain separately reviewed.
